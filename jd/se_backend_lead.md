**Job title** Senior Backend Engineer – Core Services
**Division:** Meridian Systems
**Location:** Remote (North America)
**Recruiter** Full name

## Job summary
Meridian Systems is scaling its cloud-native logistics platform and seeking a Senior Backend Engineer to lead the evolution of our core services. You will architect resilient APIs, champion observability, and collaborate closely with product and data teams to unlock new features for global shipping partners.

## Job descriptions
- Design and implement distributed services in Go and Python that power shipment orchestration.
- Own the roadmap for API performance, including latency reduction and caching strategy.
- Establish infrastructure-as-code templates (Terraform) and CI/CD pipelines for new microservices.
- Partner with SRE to define observability SLIs/SLOs and incident response runbooks.
- Mentor engineers through code reviews, pair programming, and architecture sessions.

## Job Requirement
- 6+ years of backend development experience with modern microservice architectures.
- Deep knowledge of Go or Python, PostgreSQL, and event-driven systems (Kafka preferred).
- Proven success deploying workloads to AWS or GCP using Terraform.
- Experience with container orchestration (Kubernetes) and service mesh patterns.
- Excellent communication skills for working across engineering and product stakeholders.

## Education
- Bachelor's or Master's degree in Computer Science, Software Engineering, or related field.
- Equivalent professional experience in backend engineering may substitute for formal degree.

## Skills
- **Programming Languages:** Go, Python, SQL
- **Databases:** PostgreSQL, Redis, distributed data stores
- **Event Streaming:** Apache Kafka, message queues, event-driven architecture
- **Cloud Platforms:** AWS (EC2, RDS, Lambda, S3) or GCP
- **Infrastructure as Code:** Terraform, CloudFormation
- **Container Orchestration:** Kubernetes, Docker, Helm, service mesh (Istio/Linkerd)
- **CI/CD:** GitHub Actions, GitLab CI, Jenkins
- **Observability:** Prometheus, Grafana, Datadog, distributed tracing, SLI/SLO design
- **API Design:** REST, gRPC, GraphQL, API versioning and performance optimization

## Competencies
- **Technical Leadership:** Architects scalable distributed systems and sets technical direction for teams.
- **Mentorship:** Actively develops junior engineers through code reviews and knowledge sharing.
- **Ownership:** Takes end-to-end responsibility for services from design through production operations.
- **Collaboration:** Works effectively across engineering, product, and SRE teams.
- **Performance Focus:** Obsessed with latency, throughput, and system reliability.
- **Communication:** Explains complex technical concepts clearly to diverse stakeholders.
