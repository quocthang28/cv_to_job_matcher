**Division:** LumaFit Labs
**Location:** Austin, TX (Hybrid)
**Recruiter** Full name

## Job summary
LumaFit Labs builds connected fitness experiences that bridge in-app coaching with wearable insights. We are hiring a Mobile Software Engineer to accelerate our React Native roadmap and deliver high-quality releases across iOS and Android.

## Job descriptions
- Implement new training modules, biometric dashboards, and social features in React Native.
- Integrate Bluetooth LE and Apple Health/Google Fit data streams with real-time sync.
- Optimize rendering performance, offline caching, and accessibility compliance.
- Collaborate with design to prototype and ship polished user flows using Storybook.
- Participate in feature planning, sprint ceremonies, and incident retrospectives.

## Job Requirement
- 4+ years of professional experience building mobile applications.
- Fluency with React Native, TypeScript, Redux Toolkit, and native module bridges.
- Solid understanding of mobile CI/CD (Bitrise, Fastlane) and OTA update systems.
- Familiarity with Node.js or Python backends and REST/GraphQL APIs.
- Passion for crafting intuitive, inclusive user experiences.

## Education
- Bachelor's degree in Computer Science, Software Engineering, or related technical field.
- Equivalent professional experience in mobile development may substitute for formal degree.

- **Mobile Frameworks:** React Native, Expo, native module development
